メスイサ対応！VRC7アダプター

コナミVRC7音源搭載ファミコンカセットの「ラグランジュポイント」をMSX-MUSIC互換💦？?のMSX音源カートリッジとして使用する為の変換アダプターです。別途、FMBIOSファイル(16kバイト)が必要です。

* MSX-MUSIC(YM2413)と本アダプター(VRC7)の主な違い

プリセット音色が違う。
VRC7にはリズム音源が無い。
VRC7は音声が歪みやすい(クリップしやすい)ので楽曲にもよるが音量を絞る必要がある。ここでいう音量はオーディオアンプの音量ではなく音量レジスターで設定する音量の事です。
発声中にリセット・素早く電源OFF/ONを行なうとしばらく音が出続ける。MSXシステム起動時に本アダプターのBIOSがロードされると消音されます。
IOポートやレジスターの仕様・操作方法は基本的に同一です。

* ご使用の前に

まず御自分で用意したFMBIOSファイル(16kバイト)を本アダプターにインストールする必要があります。

FMBIOSインストール方法

1. FMBIOSファイル(16kバイト)を用意します。

以下の機種のものやblueMSX付属のMSX2PMUS.romが使用出来ます。
Panasonic FS-A1WSX
Panasonic FS-A1WX
Sanyo PHC-70FD
Sanyo PHC-70FD2
Sony HB-F1XDJ
Sony HB-F1XV

ここで用意したファイルをFMBIOS.romとします。

2. vrc7.binファイルの後ろに1で用意したFMBIOSを連結します。

unixのcatコマンドを使用する例
$ cat vrc7.bin FMBIOS.rom > firmware.bin

windowsのcopyコマンドを使用する例
>copy /b vrc7.bin + FMBIOS.rom firmware.bin

3. uf2conv.exeを用いて2で作成したfirmware.binをuf2ファイルに変換します。

例: windowsコマンドプロンプト上で
uf2conv.exe firmware.bin firmware.uf2

uf2conv.exeはhttps://github.com/piigaa-densetu-two-dai/MSXpiにあります。

4. MSXに挿さっていない・ラグランジュポイントが挿さっていない状態の本アダプターをブートモードでPCに接続します。

本アダプター裏から見えるBOOTSELボタンを爪楊枝等で押しながらPCとUSB接続して下さい。
接続が成功するとドライブが認識されます。

5. 本アダプターに3で作成したfirmware.uf2ファイルを書き込みします。

4で認識されたドライブにfirmware.uf2をドラッグアンドドロップ(コピー)します。
コピーが完了するとドライブが見えなくなります。

6. 書込みが終わったらPCから外して完了

* 使用方法

まず電源設定(5V/12V)ジャンパーを設定します。

5V設定：全てのMSXで使用出来ますが電源のノイズがそのまま音声ノイズとして漏れ出してしまうという欠点があります。
12V設定：低ノイズになりますがカシオのMSXやメスイサ等、12Vが供給されていないスロットでは使用出来ません。故障につながる可能性があるので12Vが供給されていないスロットでは設定しないで下さい。

ジャンパ設定が済んだら本アダプターの上側にラグランジュポイント、下側にMSXを装着して準備完了です。くれぐれも向きを間違えないように注意して下さい。

* 本アダプター上のステレオジャックについて

ステレオジャックにプラグが挿さっていない場合はVRC7の音声はMSX本体から出力されます。
プラグが挿さっている場合はプラグからVRC7の音声が出力されます。MSX本体側からは出力されません。
出力される音声はモノラルですがジャックはステレオ仕様なのでステレオプラグを挿して使用して下さい。
モノラルプラグは挿さないで下さい。音出ません。

* 御注意
回路を簡素にする為に信号電圧レベル変換回路を省略しています
RP2040のIOピン(プラス側にダイオードが入っていないピンのみ)をMSXのスロット端子に直結しています。
実質的に問題ないであろう事を確認していますが定格外の使い方をしているのでその辺自己責任でお願いします。
